## 版本概览

根据 `setup.cfg` 文件中的元数据，poppt 库的当前版本为 **0.1.1**。该版本是一个早期开发版本，表明库正处于功能完善和稳定性的初步阶段。项目通过 `setuptools` 进行打包管理，并依赖于 `pywin32`、`poprogress`、`pofile` 和 `Pillow` 等核心库来实现其自动化办公功能。

poppt 是一个专注于 PPT 自动化操作的 Python 工具库，主要提供以下三大核心功能：
- **PPT 转 PDF**：将 PPT 或 PPTX 文件批量转换为 PDF 格式
- **PPT 转图片**：将 PPT 的每一页导出为独立图片，或合并为一张长图
- **合并 PPT**：将多个 PPT 文件合并成一个完整的演示文稿

这些功能通过简洁的 API 接口暴露给用户，如 `ppt2pdf`、`ppt2img` 和 `merge4ppt`，极大地简化了办公自动化的流程。

### v0.1.1 (当前版本)

- **发布日期**：未在代码库中明确记录，但根据文件创建时间推断为 2022 年中后期
- **贡献者**：CoderWanFeng（程序员晚枫）
- **新增功能**：
  - 实现 `ppt2pdf` 功能，支持单个或批量 PPT 文件转换为 PDF（[参考](file://poppt/api/ppt.py#L20-L31)）
  - 实现 `ppt2img` 功能，支持将 PPT 转换为独立图片或合并为长图（[参考](file://poppt/api/ppt.py#L34-L50)）
  - 实现 `merge4ppt` 功能，支持将多个 PPT 文件合并为一个（[参考](file://poppt/api/ppt.py#L53-L65)）
- **改进之处**：
  - 使用 `win32com.client` 调用本地 PowerPoint 应用程序，确保转换质量（[参考](file://poppt/core/PPTType.py#L8)）
  - 集成 `poprogress` 库，为文件处理过程提供进度条显示（[参考](file://poppt/core/PPTType.py#L14)）
  - 利用 `pofile` 库进行文件路径和后缀名的便捷操作（[参考](file://poppt/core/PPTType.py#L12)）
- **已知问题**：
  - 依赖 Windows 系统和本地安装的 Microsoft PowerPoint，不具备跨平台兼容性
  - 在 `ppt2img` 的合并模式下，生成长图时未对图片进行排序优化，可能导致幻灯片顺序错乱（[参考](file://poppt/core/PPTType.py#L187) 中使用了按文件名长度排序的临时方案）
  - `merge4ppt` 功能在合并后调用 `Application.Quit()` 会直接关闭 PowerPoint 应用，可能影响用户正在进行的其他演示文稿操作

## 语义化版本说明

poppt 库遵循语义化版本控制（Semantic Versioning）规范，版本号格式为 `主版本号.次版本号.修订号`。

- **主版本号 (Major)**：当进行不兼容的 API 修改时递增。例如，如果未来版本将 `ppt2img` 的参数顺序或名称更改，或者移除某个功能，则主版本号将从 0 增至 1。
- **次版本号 (Minor)**：当以向后兼容的方式添加新功能时递增。例如，v0.1.1 在 v0.1.0 的基础上添加了 `merge4ppt` 功能，因此次版本号从 0 增至 1。
- **修订号 (Patch)**：当进行向后兼容的问题修正时递增。例如，修复 `ppt2pdf` 转换过程中的一个 bug，但不改变其接口或行为。

当前版本 `0.1.1` 表明：
- 主版本号为 `0`，表示项目仍处于初始开发阶段，API 可能不稳定，不建议在生产环境中大规模使用。
- 次版本号为 `1`，表示自初始版本以来，已经添加了至少一个新功能（即 `merge4ppt`）。
- 修订号为 `1`，表示在 `0.1.x` 系列中已经进行了一次错误修复或小的改进。

## 向后兼容性与升级指南

### 向后兼容性策略

poppt 库在 `0.x` 版本阶段，向后兼容性不是强制保证的。开发者可能会根据用户反馈和功能需求对 API 进行调整。然而，对于 `0.1.1` 版本中的三个核心函数（`ppt2pdf`、`ppt2img`、`merge4ppt`），预计在短期内会保持接口稳定。

### 升级注意事项

- **从 v0.1.0 升级到 v0.1.1**：
  - **破坏性变更**：无。v0.1.1 是在 v0.1.0 基础上的功能增强，所有原有 API 均保持不变。
  - **新增功能**：可以开始使用 `merge4ppt` 函数来合并多个 PPT 文件。
  - **升级步骤**：直接通过 pip 更新即可：
    ```bash
    pip install -i https://mirrors.aliyun.com/pypi/simple/ poppt -U
    ```

- **未来升级建议**：
  - 在升级前，务必查阅 `README.md` 和 `CHANGELOG`（如果未来创建）以了解变更内容。
  - 在生产环境中升级前，先在测试环境中验证新版本的功能和稳定性。
  - 由于库依赖 Windows 和 PowerPoint，确保目标机器上已正确安装相关软件。
